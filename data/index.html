project 03 · statistics · experiment design

Proving a Headline Number Was Wrong (MSc dissertation)

The questionAn AI model reported good accuracy. Was the number real, or was it coming from shortcuts?
What I didDesigned a control: run the same questions with the input replaced by random noise. If accuracy holds up on noise, the input is not being used. Paired McNemar tests on every comparison, bootstrap confidence intervals, and an openly reported correction when a filtering error turned up.
